1Maşğulot maqsadi

Turli mexanik sistemalar (Atvud maşinasi, aylanayotgan halqadagi munçoq, qöş mayatnik) uçun Lagranj funksiyasini tuziş, ikkinçi tur Lagranj tenglamalarini yoziş va yeçiş.

Nazariy asos: 4-ma’ruza. Ta’lim natijalari: TN4, TN5, TN16, TN17.

Kerakli vositalarKalkulyator, Python (Google Colab yoki Jupyter), darslikdagi interaktiv model.

2Qisqaça nazariy asos

Algoritm: umumlaşgan koordinatalar → \(T(q,\dot q)\) → \(U(q)\) → \(L=T-U\) → \(\frac{d}{dt}\frac{\partial L}{\partial\dot q_i}=\frac{\partial L}{\partial q_i}\). Qöş mayatnik (\(m_1,m_2,l_1,l_2\)):

$$L=\frac{m_1+m_2}{2}l_1^2\dot\varphi_1^2+\frac{m_2}{2}l_2^2\dot\varphi_2^2+m_2l_1l_2\dot\varphi_1\dot\varphi_2\cos(\varphi_1-\varphi_2)+(m_1+m_2)gl_1\cos\varphi_1+m_2gl_2\cos\varphi_2.$$

Kiçik tebranişlarda (\(m_1=m_2\), \(l_1=l_2=l\)) xos çastotalar \(\omega^2=(2\mp\sqrt2)g/l\). Katta amplitudalarda harakat xaotik böladi.

3Işlangan masalalar

1-masala. Atvud maşinasi

Şart. \(m_1=3\) kg va \(m_2=2\) kg yuklar vaznsiz blok orqali osilgan. Lagranj tenglamasidan tezlanişni toping. Blok \(I/R^2=1\) kg bölsa-çi?

Yeçim

\(q=x\): \(L=\frac12(m_1+m_2+I/R^2)\dot x^2+(m_1-m_2)gx\) ⇒ \(a=\frac{(m_1-m_2)g}{m_1+m_2+I/R^2}\). Vaznsiz blokda \(a=1{,}96\) m/s², \(I/R^2=1\) kg da \(a=1{,}64\) m/s².

2-masala. Aylanayotgan halqadagi munçoq

Şart. Radiusi \(R=0{,}2\) m halqa vertikal öq atrofida \(\Omega=10\) rad/s bilan aylanmoqda. Munçoqning harakat tenglamasi va muvozanat holatlari?

Yeçim

\(L=\frac m2R^2(\dot\theta^2+\Omega^2\sin^2\theta)+mgR\cos\theta\) ⇒ \(\ddot\theta=\sin\theta\,(\Omega^2\cos\theta-g/R)\). Muvozanatlar: \(\theta=0\) (\(\Omega^2\gt g/R\) bölgani uçun beqaror), \(\cos\theta_0=g/(R\Omega^2)=0{,}49\) ⇒ \(\theta_0=60{,}6^\circ\) (turğun).

3-masala. Qöş mayatnik normal modalari

Şart. \(m_1=m_2\), \(l_1=l_2=1\) m qöş mayatnikning kiçik tebranişlar çastotalarini toping.

Yeçim

\(\omega_{1,2}=\sqrt{(2\mp\sqrt2)g/l}\): \(\omega_1=2{,}40\) rad/s (\(A_2/A_1=\sqrt2\), bir fazada), \(\omega_2=5{,}79\) rad/s (\(A_2/A_1=-\sqrt2\), qarama-qarşi fazada).

4Darsda mustaqil yeçiş uçun masalalar

  1. Qözğalmas qiya tekislikda (\(\alpha\)) işqalanişsiz sirpanayotgan jism uçun \(L\) va tezlaniş?
    Javob

    \(L=\frac m2\dot s^2+mgs\sin\alpha\), \(a=g\sin\alpha\)

  2. Prujinali mayatnik (\(k\), \(l_0\), tekislikda) uçun Lagranj funksiyasi?
    Javob

    \(L=\frac m2(\dot r^2+r^2\dot\varphi^2)-\frac k2(r-l_0)^2+mgr\cos\varphi\)

  3. Munçoq masalasida \(\Omega\) ning qaysi qiymatidan boşlab yon muvozanat paydo böladi (\(R=0{,}2\) m)?
    Javob

    \(\Omega_{kr}=\sqrt{g/R}=7{,}0\) rad/s

  4. Osiliş nuqtasi gorizontal \(x_0=a\cos\gamma t\) böyiça tebranayotgan mayatnik tenglamasi?
    Javob

    \(l\ddot\varphi+g\sin\varphi=a\gamma^2\cos\gamma t\cos\varphi\)

5Interaktiv model: Qöş mayatnik

Model özi parametrlarni özgartirib, natijani tuşuntiradi; söng boşqaruv sizga ötadi.
  1. Bu qöş mayatnik. Kiçik burçaklarda harakat ikki normal moda yiğindisi va oldindan aytib böladigan. Puşti nusxa asosiy mayatnik bilan ustma-ust ketmoqda.
  2. Katta burçaklarda harakat xaotik böladi. Puşti nusxaning boşlanğiç burçagi atigi mingdan bir gradusga farq qiladi, lekin bir neça sekunddan keyin ular butunlay ajraladi.
  3. Pastki yukni oğirlaştiramiz. Normal çastotalar özgardi, lekin energiya xatosi juda kiçik: Runge–Kutta usuli töğri işlayapti.
  4. Namoyiş tugadi. Bu model amaliy maşğulotdagi Lagranj tenglamalarining sonli yeçimidir.

6Kompyuterda modellaştiriş

Python (Colab/Jupyter) — nusxalab işga tuşiring va natijani qölda hisob bilan soliştiring (TN12, TN25).

import numpy as np
# Qo'sh mayatnik: Lagranj tenglamalarini RK4 bilan yechish, energiya nazorati
g, m1, m2, l1, l2 = 9.81, 1, 1, 1, 1
def f(s):
    a, b, wa, wb = s; d = a - b
    M = np.array([[(m1+m2)*l1, m2*l2*np.cos(d)], [l1*np.cos(d), l2]])
    rhs = np.array([-m2*l2*wb**2*np.sin(d) - (m1+m2)*g*np.sin(a),
                     l1*wa**2*np.sin(d) - g*np.sin(b)])
    return np.array([wa, wb, *np.linalg.solve(M, rhs)])
def energy(s):
    a, b, wa, wb = s
    T = (m1+m2)/2*l1**2*wa**2 + m2/2*l2**2*wb**2 + m2*l1*l2*wa*wb*np.cos(a-b)
    return T - (m1+m2)*g*l1*np.cos(a) - m2*g*l2*np.cos(b)
s = np.array([np.radians(120), np.radians(-10), 0, 0]); dt = 1e-3; E0 = energy(s)
for k in range(10001):
    if k % 2000 == 0: print(f"t={k*dt:4.1f}  phi1={np.degrees(s[0]):8.1f}  phi2={np.degrees(s[1]):8.1f}  dE={energy(s)-E0:.2e}")
    k1=f(s); k2=f(s+dt/2*k1); k3=f(s+dt/2*k2); k4=f(s+dt*k3); s = s + dt/6*(k1+2*k2+2*k3+k4)

8Darsdagi faollikni baholaş (JN tarkibida 20 ball)

Yuqori18–20Masalaning fizik mohiyatini töliq tuşunadi, erkinlik darajalari va umumlaşgan koordinatalarni töğri tanlaydi, Lagranj yoki Gamilton tenglamalarini (Puasson qavslari, kanonik tenglamalar, Gamilton–Yakobi usuli) bexato tuzib, mustaqil yeçiş modelini quradi.
