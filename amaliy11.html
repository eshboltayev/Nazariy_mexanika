1Maşğulot maqsadi

Turli sistemalar uçun Gamilton funksiyasini tuziş, kanonik tenglamalarni yoziş va yeçiş, fazaviy trayektoriyalarni quriş.

Nazariy asos: 10-ma’ruza. Ta’lim natijalari: TN4, TN5, TN16, TN17.

Kerakli vositalarKalkulyator, Python (Google Colab yoki Jupyter), darslikdagi interaktiv model.

2Qisqaça nazariy asos

Tartib: \(L\) → \(p_i=\partial L/\partial\dot q_i\) → \(\dot q_i\) ni \(p\) orqali ifodalaş → \(H=\sum p_i\dot q_i-L\). Muhim misollar:

  • Markaziy maydon: \(H=\frac{p_r^2}{2m}+\frac{p_\varphi^2}{2mr^2}+U(r)\).
  • Mayatnik: \(H=\frac{p_\theta^2}{2ml^2}-mgl\cos\theta\).
  • Elektromagnit maydondagi zaryad: \(H=\frac{(\vec p-q\vec A)^2}{2m}+q\varphi\).
$$\dot q_i=\frac{\partial H}{\partial p_i},\qquad\dot p_i=-\frac{\partial H}{\partial q_i}.$$

3Işlangan masalalar

1-masala. Markaziy maydon

Şart. Qutb koordinatalarida markaziy maydondagi zarra uçun \(H\) va kanonik tenglamalarni yozing.

Yeçim

\(p_r=m\dot r\), \(p_\varphi=mr^2\dot\varphi\); \(H=\frac{p_r^2}{2m}+\frac{p_\varphi^2}{2mr^2}+U\). \(\dot p_\varphi=-\partial H/\partial\varphi=0\) (moment saqlanadi), \(\dot p_r=\frac{p_\varphi^2}{mr^3}-U'(r)\).

2-masala. Ossilyator

Şart. \(m=0{,}5\) kg, \(k=2\) N/m, \(q_0=0{,}1\) m, \(p_0=0\). Kanonik tenglamalarni yeçing, energiya va fazaviy trayektoriya?

Yeçim

\(\omega=2\) rad/s. \(q=0{,}1\cos2t\), \(p=-0{,}1\sin2t\) kg·m/s. \(E=kq_0^2/2=0{,}01\) J. Trayektoriya: \(q^2/0{,}01+p^2/0{,}01=1\) — bu holda aylana.

3-masala. Puasson qavsi

Şart. \(\{p_x,L_z\}\) ni hisoblang (\(L_z=xp_y-yp_x\)).

Yeçim

\(\{p_x,L_z\}=\sum\left(\frac{\partial p_x}{\partial q}\frac{\partial L_z}{\partial p}-\frac{\partial p_x}{\partial p}\frac{\partial L_z}{\partial q}\right)=-\frac{\partial L_z}{\partial x}=-p_y\).

4Darsda mustaqil yeçiş uçun masalalar

  1. Bir jinsli oğirlik maydonida vertikal otilgan jism uçun \(H\) va kanonik tenglamalar?
    Javob

    \(H=p^2/2m+mgz\); \(\dot z=p/m\), \(\dot p=-mg\)

  2. \(L=\frac m2(\dot x^2+\dot y^2)+\frac{qB}{2}(x\dot y-y\dot x)\) uçun \(p_x\), \(p_y\)?
    Javob

    \(p_x=m\dot x-qBy/2\), \(p_y=m\dot y+qBx/2\)

  3. Mayatnik uçun separatrisa energiyasi?
    Javob

    \(E=mgl\) (\(H\) da \(U=-mgl\cos\theta\) bilan)

  4. \(\{L_x,L_y\}\) = ?
    Javob

    \(L_z\)

5Interaktiv model: Fazaviy portret

Model özi parametrlarni özgartirib, natijani tuşuntiradi; söng boşqaruv sizga ötadi.
  1. Bu model fazaviy fazoni körsatadi. Garmonik ossilyatorning trayektoriyasi ellips. Energiya sakkiz joul, ellips yuzasi sakkiz pi.
  2. Energiyani oşirsak, ellips kattalaşadi. Lekin davr özgarmaydi: garmonik ossilyator izoxron.
  3. Mayatnikka ötamiz. Kiçik energiyada trayektoriya yopiq egri çiziq — tebraniş. Qizil uzuq çiziq — separatrisa.
  4. Energiyani separatrisaga yaqinlaştiramiz. Davr keskin ortadi: mayatnik yuqori nuqtada uzoq töxtab qoladi.
  5. Separatrisadan yuqori energiyada mayatnik töxtamasdan aylanadi, trayektoriya oçiq. Namoyiş tugadi.

6Kompyuterda modellaştiriş

Python (Colab/Jupyter) — nusxalab işga tuşiring va natijani qölda hisob bilan soliştiring (TN12, TN25).

import numpy as np
# Mayatnik fazaviy portreti: simplektik (leapfrog) integrallash
g, l, m = 9.81, 1.0, 1.0
H = lambda q, p: p**2/(2*m*l**2) - m*g*l*np.cos(q)
dt = 1e-3
for E in (-5, 0, 9.81, 15):
    q = 0.0; p = np.sqrt(2*m*l**2*(E + m*g*l)); qmax = 0
    for k in range(20000):
        p -= dt/2*m*g*l*np.sin(q); q += dt*p/(m*l**2); p -= dt/2*m*g*l*np.sin(q)
        qmax = max(qmax, abs(q))
    turi = "tebranish" if qmax < np.pi else "aylanish/separatrisa"
    print(f"E={E:6.2f} J  q_max={np.degrees(qmax):8.1f}°  H oxirida={H(q, p):.4f}  -> {turi}")
