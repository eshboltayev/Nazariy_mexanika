1Maşğulot maqsadi

Majburiy tebranişlar amplitudasi, fazasi, yutilgan quvvat va rezonans egri çiziğining kengligini hisoblaş; tepkilar va kinematik qözğatiş masalalarini yeçiş.

Nazariy asos: 6-ma’ruza. Ta’lim natijalari: TN9, TN22, TN25.

Kerakli vositalarKalkulyator, Python (Google Colab yoki Jupyter), darslikdagi interaktiv model.

2Qisqaça nazariy asos

Barqaror rejim: \(b=\dfrac{F_0/m}{\sqrt{(\omega_0^2-\gamma^2)^2+4\beta^2\gamma^2}}\), \(\operatorname{tg}\delta=\dfrac{2\beta\gamma}{\omega_0^2-\gamma^2}\). Örtaça yutilgan quvvat:

$$\langle P\rangle=\frac{F_0^2}{m}\frac{\beta\gamma^2}{(\omega_0^2-\gamma^2)^2+4\beta^2\gamma^2},\qquad\langle P\rangle_{max}=\frac{F_0^2}{4m\beta}.$$

Yarim quvvat böyiça kenglik \(\Delta\gamma=2\beta\), asllik \(Q=\omega_0/\Delta\gamma\). Söniş bölmaganda, \(\gamma\approx\omega_0\) da tepkilar kuzatiladi: \(x\propto\sin\frac{\varepsilon t}{2}\), \(\varepsilon=\gamma-\omega_0\).

3Işlangan masalalar

1-masala. Rezonansdan taşqarida

Şart. \(m=0{,}5\) kg, \(\omega_0=20\) rad/s, \(\beta=1\) s⁻¹, \(F_0=2\) N, \(\gamma=15\) rad/s. Amplituda va faza siljişi?

Yeçim

\(b=4/\sqrt{175^2+900}=4/177{,}6=0{,}0225\) m; \(\operatorname{tg}\delta=30/175\) ⇒ \(\delta=9{,}7^\circ\) (siljiş kuçdan orqada).

2-masala. Rezonansda yutilgan quvvat

Şart. Şu sistema uçun \(\langle P\rangle_{max}\) va yarim quvvat kengligi?

Yeçim

\(\langle P\rangle_{max}=F_0^2/(4m\beta)=4/2=2\) Vt. \(\Delta\gamma=2\beta=2\) rad/s, \(Q=20/2=10\).

3-masala. Kinematik qözğatiş

Şart. Avtomobil osmasining xos çastotasi \(f_0=1{,}5\) Gs. Yöl notekisliklari orasidagi masofa 5 m bölsa, qaysi tezlikda rezonans böladi?

Yeçim

Qözğatiş çastotasi \(f=v/\lambda\) ⇒ \(v=f_0\lambda=7{,}5\) m/s = 27 km/soat.

    \(2\pi/|\gamma-\omega_0|=6{,}28\) s

  3. Asllik \(Q=50\) bölsa, rezonansdagi amplituda statik siljişdan neça marta katta?
    Javob

    ≈ 50

  4. Sönmaydigan ossilyatorga \(\gamma=\omega_0\) kuç ta’sir qilsa, \(x(t)\) qanday ösadi?
    Javob

5Interaktiv model: Majburiy tebranişlar, rezonans

Model özi parametrlarni özgartirib, natijani tuşuntiradi; söng boşqaruv sizga ötadi.
  1. Bu model majburiy tebranişlarni körsatadi. Xos çastota yigirma radian sekund. Majburlovçi çastota ön, amplituda kiçik.
  2. Çastotani yigirmaga tenglaştiramiz. Rezonans: amplituda ön santimetrgaça ösdi, bu statik siljişdan ön marta katta. Asllik önga teng.
  3. Sönişni tört marta oşiramiz. Rezonans egri çiziği pasaydi va kengaydi, amplituda tört marta kamaydi.
  4. Çastota xos çastotadan ança katta bölsa, jism inersiyasi tufayli deyarli harakatlanmaydi va qarama-qarşi fazada tebranadi.
  5. Öng grafikda tebraniş tinçlikdan boşlanib, ötiş jarayonidan keyin barqaror amplitudaga çiqadi. Endi özingiz tajriba qiling.

6Kompyuterda modellaştiriş

Python (Colab/Jupyter) — nusxalab işga tuşiring va natijani qölda hisob bilan soliştiring (TN12, TN25).

import numpy as np
# Rezonans egri chizig'i va yarim quvvat kengligi; RK4 bilan barqaror amplituda
m, w0, beta, F0 = 0.5, 20.0, 1.0, 2.0
g = np.linspace(10, 30, 2001)
b = F0/m/np.sqrt((w0**2 - g**2)**2 + 4*beta**2*g**2)
P = F0**2/m*beta*g**2/((w0**2 - g**2)**2 + 4*beta**2*g**2)
i = P.argmax(); half = g[P >= P[i]/2]
print(f"b_max={b.max():.4f} m at {g[b.argmax()]:.2f} rad/s;  P_max={P[i]:.3f} W;  kenglik={half[-1]-half[0]:.2f} rad/s")
def steady(gam, T=20.0, dt=1e-3):
    x = v = 0.0; amp = 0
    for k in range(int(T/dt)):
        t = k*dt; a = F0/m*np.cos(gam*t) - 2*beta*v - w0**2*x
        v += a*dt; x += v*dt
        if t > T - 2: amp = max(amp, abs(x))
    return amp
for gam in (15, 20, 25): print(f"gamma={gam}: sonli b={steady(gam):.4f}")
