1Maşğulot maqsadi

Sferik koordinatalarda holat, tezlik va kinetik energiyani ifodalaş, sfera sirtidagi harakat va sferik mayatnik masalalarini Lagranj funksiyasi orqali tahlil qiliş.

Nazariy asos: 2-ma’ruza. Ta’lim natijalari: TN2, TN3, TN15.

Kerakli vositalarKalkulyator, Python (Google Colab yoki Jupyter), darslikdagi interaktiv model.

2Qisqaça nazariy asos

\(x=r\sin\theta\cos\varphi\), \(y=r\sin\theta\sin\varphi\), \(z=r\cos\theta\); \(0\le\theta\le\pi\), \(0\le\varphi\lt2\pi\). Lame koeffitsiyentlari \((1,\,r,\,r\sin\theta)\):

$$v^2=\dot r^2+r^2\dot\theta^2+r^2\sin^2\theta\,\dot\varphi^2,\qquad dV=r^2\sin\theta\,dr\,d\theta\,d\varphi.$$

Sferik mayatnik (\(\theta\) pastga yönalgan vertikaldan): \(L=\frac{ml^2}{2}(\dot\theta^2+\sin^2\theta\,\dot\varphi^2)+mgl\cos\theta\). \(\varphi\) siklik, şuning uçun \(p_\varphi=ml^2\sin^2\theta\,\dot\varphi=\text{const}\). Konus mayatnik (\(\theta=\text{const}\)) uçun \(\dot\varphi^2=g/(l\cos\theta)\).

3Işlangan masalalar

1-masala. Sfera sirtida harakat

Şart. Zarra radiusi \(R=2\) m sfera sirtida harakatlanmoqda; biror paytda \(\theta=60^\circ\), \(\dot\theta=1\) rad/s, \(\dot\varphi=2\) rad/s. Tezlikni toping.

Yeçim

\(\dot r=0\): \(v^2=R^2(\dot\theta^2+\sin^2\theta\,\dot\varphi^2)=4(1+0{,}75\cdot4)=16\) ⇒ \(v=4\) m/s.

2-masala. Koordinatalarni aniqlaş

Şart. \((x,y,z)=(-2;\,2;\,2\sqrt2)\) nuqtaning sferik koordinatalarini toping.

Yeçim

\(r=\sqrt{4+4+8}=4\); \(\cos\theta=2\sqrt2/4=0{,}707\) ⇒ \(\theta=45^\circ\); \(x\lt0,\ y\gt0\) ⇒ \(\varphi=135^\circ\).

3-masala. Konus mayatnik

Şart. \(l=1\) m ip bilan mayatnik vertikaldan \(\theta=30^\circ\) oğib, aylana böylab harakatlanadi. Burçak tezlik va davrni toping.

Yeçim

\(\theta\) böyiça Lagranj tenglamasi: \(ml^2\sin\theta\cos\theta\,\dot\varphi^2-mgl\sin\theta=0\) ⇒ \(\dot\varphi=\sqrt{g/(l\cos\theta)}=\sqrt{9{,}81/0{,}866}=3{,}37\) rad/s, \(T=2\pi/\dot\varphi=1{,}87\) s.

4Darsda mustaqil yeçiş uçun masalalar

  1. \((r,\theta,\varphi)=(3;\,90^\circ;\,270^\circ)\) — Dekart koordinatalari?
    Javob

    \((0;\,-3;\,0)\)

  2. Sferik koordinatalarda integrallab, şar hajmini toping.
    Javob

    \(\int_0^R r^2dr\int_0^\pi\sin\theta\,d\theta\int_0^{2\pi}d\varphi=\frac43\pi R^3\)

  3. \(l=0{,}5\) m, \(\theta=60^\circ\) konus mayatnik burçak tezligi?
    Javob

    \(\sqrt{9{,}81/0{,}25}=6{,}26\) rad/s

  4. Sferik koordinatalarda erkin zarra Lagranj funksiyasini yozing va siklik koordinatani körsating.
    Javob

    \(L=\frac m2(\dot r^2+r^2\dot\theta^2+r^2\sin^2\theta\dot\varphi^2)\); \(\varphi\) siklik, \(p_\varphi=mr^2\sin^2\theta\,\dot\varphi\)

5Interaktiv model: Koordinatalar sistemalari

Model özi parametrlarni özgartirib, natijani tuşuntiradi; söng boşqaruv sizga ötadi.
  1. Bu model nuqtaning Dekart, silindrik va sferik koordinatalarini birga körsatadi. Radius ikki, teta va fi qirq beş gradus. Dekart koordinatalari bir, bir va ikkining ildizi.
  2. Teta burçagini töqson gradusga özgartiramiz. Nuqta ekvator tekisligiga tuşdi, z koordinata nolga teng böldi.
  3. Teta yuz ellik, fi ikki yuz yigirma gradus. Nuqta pastki yarim fazoga va uçinçi çorakka ötdi. Sferik koordinatalar markaziy simmetriyali masalalarda qulay.
  4. Silindrik sistemaga ötamiz. Endi nuqta öqdan masofa, fi burçagi va balandlik bilan beriladi. Kulrang halqa — özgarmas ro radiusli aylana.
  5. Namoyiş tugadi. Işlangan misoldagi nuqtani özingiz kiritib, javobni tekşiring.

6Kompyuterda modellaştiriş

Python (Colab/Jupyter) — nusxalab işga tuşiring va natijani qölda hisob bilan soliştiring (TN12, TN25).

import numpy as np
# Sferik mayatnik: RK4 bilan integrallash va p_phi saqlanishini tekshirish
g, l = 9.81, 1.0
def f(s):
    th, w, ph, om = s
    return np.array([w, np.sin(th)*np.cos(th)*om**2 - g/l*np.sin(th), om,
                     -2*w*om*np.cos(th)/np.sin(th)])
th0 = np.radians(30); s = np.array([th0, 0.0, 0.0, np.sqrt(g/(l*np.cos(th0)))*1.1])
dt = 1e-3
for k in range(5001):
    if k % 1000 == 0:
        th, w, ph, om = s
        E = 0.5*l**2*(w**2 + np.sin(th)**2*om**2) - g*l*np.cos(th)
        print(f"t={k*dt:4.1f} s  theta={np.degrees(th):6.2f}°  p_phi={l**2*np.sin(th)**2*om:.5f}  E={E:.5f}")
    k1 = f(s); k2 = f(s + dt/2*k1); k3 = f(s + dt/2*k2); k4 = f(s + dt*k3)
    s = s + dt/6*(k1 + 2*k2 + 2*k3 + k4)
