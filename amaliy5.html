1Maşğulot maqsadi

Kuç va boşlanğiç şartlar berilganda harakat tenglamalarini integrallab, harakat qonuni va trayektoriyani topiş; muhit qarşiligi va magnit maydondagi harakatni tahlil qiliş.

Nazariy asos: 4-ma’ruza. Ta’lim natijalari: TN1, TN6, TN25.

Kerakli vositalarKalkulyator, Python (Google Colab yoki Jupyter), darslikdagi interaktiv model.

2Qisqaça nazariy asos

Dinamikaning asosiy (teskari) masalasi: \(m\ddot{\vec r}=\vec F(\vec r,\dot{\vec r},t)\), \(\vec r(0)=\vec r_0\), \(\dot{\vec r}(0)=\vec v_0\). Muhim hollar:

  • Çiziqli qarşilik \(\vec F=m\vec g-b\vec v\): \(v(t)=v_t(1-e^{-t/\tau})\), \(\tau=m/b\), \(v_t=mg/b\).
  • Kvadratik qarşilik \(F=cv^2\): \(v_t=\sqrt{mg/c}\).
  • Bir jinsli magnit maydon \(m\dot{\vec v}=q\vec v\times\vec B\): aylana, \(\omega_c=qB/m\), \(r=mv_\perp/qB\); \(B\) böylab tekis — vint çiziq.
  • Elastik kuç \(F=-kx\): \(x=A\cos(\omega t+\alpha)\), \(A=\sqrt{x_0^2+v_0^2/\omega^2}\).

3Işlangan masalalar

1-masala. Çiziqli qarşilik bilan tuşiş

Şart. \(m=10\) g şarça \(b=0{,}002\) kg/s qarşilik koeffitsiyentli muhitda tinç holatdan tuşmoqda. \(\tau\), \(v_t\) va \(t=5\) s dagi tezlik?

Yeçim

\(\tau=m/b=5\) s, \(v_t=mg/b=49{,}05\) m/s. \(v(5)=49{,}05(1-e^{-1})=31{,}0\) m/s.

2-masala. Proton magnit maydonda

Şart. Proton \(v=10^6\) m/s tezlik bilan \(B=0{,}5\) T maydonga tik uçib kirdi. Siklotron çastotasi va orbita radiusi?

Yeçim

\(\omega_c=eB/m_p=1{,}602\cdot10^{-19}\cdot0{,}5/1{,}673\cdot10^{-27}=4{,}79\cdot10^7\) rad/s; \(r=v/\omega_c=2{,}09\) sm.

3-masala. Ossilyator boşlanğiç şartlari

Şart. \(\omega=2\) rad/s, \(x_0=0{,}1\) m, \(v_0=0{,}4\) m/s. Amplituda va boşlanğiç faza?

Yeçim

\(A=\sqrt{0{,}01+0{,}04}=0{,}224\) m; \(\operatorname{tg}\alpha=-v_0/(\omega x_0)=-2\) ⇒ \(\alpha=-63{,}4^\circ\).

  1. Paraşyutçi: \(m=80\) kg, \(c=0{,}25\) kg/m. Oxirgi tezlik?

  2. Elektronning \(B=1\) mT maydondagi siklotron çastotasi \(f\)?
    Javob

    ≈ 28 MGs

  3. \(k=8\) N/m, \(m=2\) kg ossilyator davri?
    Javob

    \(T=2\pi\sqrt{m/k}=\pi\approx3{,}14\) s

  4. Kvadratik qarşilikda qiya otiş trayektoriyasi parabolaga nisbatan qanday özgaradi?
    Javob

5Interaktiv model: Trayektoriya va vektorlar

Model özi parametrlarni özgartirib, natijani tuşuntiradi; söng boşqaruv sizga ötadi.
  1. Bu model trayektoriya, tezlik va tezlaniş vektorlarini körsatadi. Parabolik harakatda bir sekundda tezlik ikki butun sakson uç, egrilik radiusi beş butun oltmiş olti metr.
  2. Ikki sekundda jism eng yuqori nuqtada. Tezlik gorizontal, tezlaniş unga tik, tangensial tezlaniş nol.
  3. Ellips böylab harakatda tezlaniş doim markazga yönalgan. Binafşa aylana — egrilik aylanasi.
  4. Sikloidada nuqta eng yuqorida va tezligi maksimal. Pastki nuqtada esa tezlik nolga teng böladi.
  5. Havo qarşiligi bilan qiya otişda trayektoriya nosimmetrik: tuşiş qismi tikroq. Namoyiş tugadi.

6Kompyuterda modellaştiriş

Python (Colab/Jupyter) — nusxalab işga tuşiring va natijani qölda hisob bilan soliştiring (TN12, TN25).

import numpy as np
# Kvadratik havo qarshiligi bilan qiya otish (RK4)
g, m, c = 9.81, 0.145, 0.0013   # beysbol to'pi
def f(s):
    x, y, vx, vy = s; v = np.hypot(vx, vy)
    return np.array([vx, vy, -c/m*v*vx, -g - c/m*v*vy])
for cc in (0.0, c):
    c = cc; v0, a = 40.0, np.radians(45)
    s = np.array([0, 0, v0*np.cos(a), v0*np.sin(a)]); dt = 1e-3; H = 0
    while s[1] >= 0:
        k1=f(s); k2=f(s+dt/2*k1); k3=f(s+dt/2*k2); k4=f(s+dt*k3)
        s = s + dt/6*(k1+2*k2+2*k3+k4); H = max(H, s[1])
    print(f"c={cc}:  uzoqlik={s[0]:.1f} m  balandlik={H:.1f} m")
