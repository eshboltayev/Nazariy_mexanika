1Maşğulot maqsadi

Markaziy maydonda harakat integrallari va effektiv potensialdan foydalanib, orbita parametrlari, buriliş nuqtalari, Kepler qonunlari va kosmik manyovrlar bilan boğliq masalalarni yeçiş.

Nazariy asos: 7-ma’ruza. Ta’lim natijalari: TN5, TN8, TN21.

Kerakli vositalarKalkulyator, Python (Google Colab yoki Jupyter), darslikdagi interaktiv model.

2Qisqaça nazariy asos

Integrallar: \(M=\mu r^2\dot\varphi\), \(E=\frac{\mu\dot r^2}{2}+U_{eff}(r)\), \(U_{eff}=U+\frac{M^2}{2\mu r^2}\). Trayektoriya:

$$\varphi=\int\frac{M\,dr/r^2}{\sqrt{2\mu(E-U)-M^2/r^2}}+\text{const}.$$

Aylana orbita \(U_{eff}\) minimumida: \(U'(r_0)=M^2/\mu r_0^3\). \(U=kr^n\) uçun aylana orbita turğun bölişi şarti \(n\gt-2\). Kepler masalasi: \(a=\alpha/2|E|\), \(T^2=4\pi^2a^3/GM\), vis-viva formulasi \(v^2=GM\left(\frac2r-\frac1a\right)\).

3Işlangan masalalar

1-masala. Gomann ötişi

Şart. Kosmik apparat 300 km balandlikdagi aylana orbitadan (\(r_1=6671\) km) geostatsionar orbitaga (\(r_2=42\,164\) km) Gomann ellipsi böylab ötadi. \(\Delta v_1\), \(\Delta v_2\) va ötiş vaqtini toping.

Yeçim

\(v_1=\sqrt{GM/r_1}=7{,}73\) km/s; \(\Delta v_1=v_1\left(\sqrt{2r_2/(r_1+r_2)}-1\right)=2{,}43\) km/s. \(v_2=3{,}07\) km/s; \(\Delta v_2=v_2\left(1-\sqrt{2r_1/(r_1+r_2)}\right)=1{,}47\) km/s. Jami 3,90 km/s. Ötiş vaqti — ellips davrining yarmi: 5,27 soat.

2-masala. Oy davri

Şart. Oy orbitasi radiusi \(a=384\,400\) km. Kepler III qonuni böyiça davrni toping (\(GM_\oplus=3{,}986\cdot10^{14}\) m³/s²).

Yeçim

\(T=2\pi\sqrt{a^3/GM}=2{,}37\cdot10^6\) s \(=27{,}45\) sutka (siderik davr 27,32 sutka; farq — Oy massasi \(m_1+m_2\) da hisobga olinmagan).

3-masala. Buriliş nuqtalari

Şart. \(\mu=1\), \(\alpha=1\), \(M=1\), \(E=-0{,}375\) birliklarda Kepler masalasida \(r_{min}\), \(r_{max}\) va eksentrisitetni toping.

Yeçim

\(E=-1/r+1/2r^2\) ⇒ \(0{,}375r^2-r+0{,}5=0\) ⇒ \(r=\frac{1\pm0{,}5}{0{,}75}\): \(r_{min}=0{,}667\), \(r_{max}=2\). \(e=\sqrt{1+2EM^2}=0{,}5\), \(a=1{,}333\) ✓.

  3. Geostatsionar orbita radiusi (\(T=86\,164\) s)?
    Javob

  4. Yöldoş perigeyda \(r_p=7000\) km, apogeyda \(r_a=14\,000\) km. Perigeydagi tezlik (vis-viva)?
    Javob

5Interaktiv model: Kepler orbitasi va U_eff

Model özi parametrlarni özgartirib, natijani tuşuntiradi; söng boşqaruv sizga ötadi.
  1. Bu model markaziy maydondagi orbitani va effektiv potensialni körsatadi. Tezlik aylana tezligiga teng, eksentrisitet nol — orbita aylana. Energiya effektiv potensial minimumida.
  2. Tezlikni yigirma foizga oşiramiz. Orbita ellipsga aylandi, eksentrisitet nol butun qirq tört yuzdan. Energiya çiziği potensial çuqurni ikki nuqtada kesadi: bu perigey va apogey.
  3. Tezlik ikkining ildizidan katta böldi. Energiya musbat, orbita oçiq — giperbola. Bu qoçiş tezligi.
  4. Tezlik yönalişini öttiz gradusga buramiz. Impuls momenti kamaydi, orbita çözilib, markazga yaqinroq ötadi.
  5. Namoyiş tugadi. Davr Keplerning uçinçi qonuniga mosligini özingiz tekşiring.

6Kompyuterda modellaştiriş

Python (Colab/Jupyter) — nusxalab işga tuşiring va natijani qölda hisob bilan soliştiring (TN12, TN25).

import numpy as np
from math import pi, sqrt
GM = 3.986e14
def hohmann(r1, r2):
    v1, v2 = sqrt(GM/r1), sqrt(GM/r2); a = (r1 + r2)/2
    dv1 = v1*(sqrt(2*r2/(r1 + r2)) - 1); dv2 = v2*(1 - sqrt(2*r1/(r1 + r2)))
    return dv1, dv2, pi*sqrt(a**3/GM)
dv1, dv2, t = hohmann(6671e3, 42164e3)
print(f"dv1={dv1/1e3:.3f} km/s  dv2={dv2/1e3:.3f} km/s  jami={(dv1+dv2)/1e3:.3f} km/s  t={t/3600:.2f} soat")
# Effektiv potensial (birliksiz): burilish nuqtalari
E, M = -0.375, 1.0
r = np.linspace(0.3, 3, 100000); Ueff = -1/r + M**2/(2*r**2)
idx = np.where(np.diff(np.sign(E - Ueff)))[0]
print("burilish nuqtalari:", r[idx].round(3))
